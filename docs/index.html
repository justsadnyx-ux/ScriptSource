Version

Current: v1.3.0

Always check for updates in the script's Updates tab.

Features

  • Main - Walk Speed, Jump Power, Gravity sliders
  • ESP - Name tags with distance on all players
  • Anti-AFK - Prevents idle kick
  • FPS Boost - Disables particles, trails, shadows
  • Bomb Game - Hot potato with 1-8s timer, pass, force pass, weld away
  • Poll - Vote on live polls started by the owner
  • Owner Panel - See ScriptSource users, kick, shutdown UI, send broadcasts
  • Auto-Update - Fetches latest version from GitHub

Owner Panel

Available to HOPOUTHECUPE2 only in-game.

Send global notifications, create polls, manage players.

Bomb Game

Hot potato mode. Timer is 1-8 seconds. Pass to random player, force pass, or weld away. Holder explodes when timer hits 0.

How to Use

  • 1. Open your executor (Xeno recommended)
  • 2. Join any Roblox game
  • 3. Paste the loadstring above
  • 4. The ScriptSource UI will appear
