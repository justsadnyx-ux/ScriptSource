  • FPS Boost - Disables particles, shadows
  • Bomb Game - Auto-pass, force transfer, manual bomb timer
  • Poll - Vote on live polls from owner
  • Key System - 24h keys, device-bound, lifetime key available
  • Owner Panel - User management, broadcasts, key generator
  • Auto-Update - Fetches latest from GitHub

How to Use

  • 1. Generate a key or enter the Giveaway for lifetime access
  • 2. Open your executor (Xeno recommended)
  • 3. Join any Roblox game
  • 4. Paste the loadstring
  • 5. Enter your key when prompted
