# Changelog

## v1.1.0 (Latest)
### New Features
- **Update Status Section** - Dedicated UI showing Up to Date / Outdated status with live checking
- **Update Now Button** - One-click update fetches latest source from GitLab
- **ESP** - Player name tags with distance tracking (always-on-top)
- **Anti-AFK** - Prevents idle kicks using VirtualUser
- **FPS Boost** - Disables particles, trails, beams, shadows, fog for max performance
- **Keybinds System** - Bind any key to any action with visual key picker
- **Server Info Panel** - Player count, ping, FPS, memory, game name
- **Speed / Jump / Gravity Sliders** - Quick character modification
- **Player Count in Footer** - Live player count in footer bar
- **3 New Themes** - Crimson, Frost added to the theme engine
- **Console Improvements** - Clear + Copy buttons, timestamped logs, info level support
- **Session State Save** - Save/restore state between sessions
- **Animated Shutdown** - Window slides down on close instead of instant destroy

### Improvements
- Cleaner update checking with visible status indicators
- Better notification stacking
- Improved drag behavior
- More descriptive error messages

## v1.0.0
### Initial Release
- Core UI library with tabs and sections
- Button, Toggle, Slider, Dropdown, Input, Paragraph, Separator, ColorPicker elements
- Script Hub with favorites, search, and one-click execute
- Theme Engine (Default, Dark, Neon, Ocean, Mint)
- Key System with attempts limit
- Built-in Console/Output
- Notification system with types
- Enhanced draggable/minimizable window with shadows
- Auto-update from GitLab remote
- Session management + clean shutdown
- Config persistence (toggles, dropdowns, favorites)
- Uptime tracking in footer
